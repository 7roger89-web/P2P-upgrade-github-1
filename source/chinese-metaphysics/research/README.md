# Per-Repository Research Index

Rule: **1 upstream repository = 1 independent research dossier.**

Không dùng rule, interpretation, case hoặc school claim của repo A để lấp khoảng trống cho repo B. Mỗi hồ sơ tự giữ scope, candidate rules, provenance gaps, validation plan và case protocol của chính nó.

## Isolation contract

Mỗi dossier dùng format tối thiểu:

```text
UPSTREAM -> PINNED SHA -> REPO CLAIMS -> CANDIDATE RULES
-> SOURCE GAPS -> VALIDATION -> CASES -> VERDICT
```

Một rule chỉ có giá trị bên trong dossier chứa nó cho tới khi Owner chủ động yêu cầu một nghiên cứu so sánh riêng. Không có “shared rule registry” ở giai đoạn này.
