This directory is separate from the immutable `source/8.4.6-C/` snapshot.

- `Hướng dẫn phần 1.docx`, `Hướng dẫn phần 2.docx`, and `skill.docx` are exact
  user-supplied background snapshots used during the Codex analysis.
- `P2P-overview-architecture-catalog.ru.txt` is the exact user-supplied Russian
  overview/catalog snapshot, preserved with SHA-256
  `90d1cd03d15667b5aa8ec12ded6245fe84f5aacd9de478f09f5777301e829341`.
- The living Google handbook is not mirrored here. Its URL, audit date, known
  section counts, and update rule are in `manifest/external-sources.json`.

Do not count these files in the 152-file release reconciliation. Compare and
version them independently when the author or user supplies an update.
