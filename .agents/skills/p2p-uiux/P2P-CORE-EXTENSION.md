## UI/UX capability extension

When a natural-language request is visual or product-interface work, route it to the installed `p2p-uiux` skill. Use the real `p2p_aesthetica` profile only when it is present and validated. If it is unavailable, report `PROFILE_UNAVAILABLE`; do not simulate it.

Before any skill is selected, the primary dispatcher records
`INITIAL_PLANNING_CLASSIFICATION`. A concrete interface, usability,
readability, accessibility, responsive, navigation, interaction, or visual
outcome is `UIUX` on that first decision even when the user is a beginner or
uncertain. Record `FINAL_ROUTING_CLASSIFICATION` separately after capability
routing; later routing must not rewrite a wrong initial classification. This
is a planning contract and does not create a second router.

This supporting domain specialist is never canonical and never changes the canonical P2P quorum denominator. The canonical set remains exactly eight identities and full governance remains `8/8`.

For material UI/UX work, keep p2p-uiux primary. The bounded certification makes
`p2p_aesthetica` automatically eligible only for a material
`ACCESSIBILITY_HEAVY` or `DENSE_WORKFLOW_FORM` problem. Generic dashboards,
story/game UI, mobile consumer UI, ecommerce, responsive-only work,
design-system-only work, visual polish, and small cosmetics remain p2p-uiux-only
by default. If the existing router marks one of the two classes eligible and
the real optional path is available, have the current native coordinator
perform the bounded review. Require the official host receipt and exact
`agent_type p2p_aesthetica`; never manually spawn or simulate. If unavailable
or unverifiable, continue through the normal verified p2p-uiux fallback.
For substantial UI/UX work, produce or update the project-owned Design System
and Design Contract, run accessibility evidence and Design Drift checks, and
ask owner approval for material visual identity, core tokens, primary
navigation, or destructive redesign. Non-UI/backend requests continue through
the existing P2P route without unnecessary Aesthetica.
