## 8. Persistence claim (verified)

- **DATABASE_REQUIRED_BY_DEFAULT = NO** — default runtime operates with browser storage only (localStorage KV + IndexedDB documents/runtime/assets).
- **OPTIONAL_PERSISTENCE = YES** — pluggable `@openmaic/storage` backends: embedded HTTP persistence (`/api/persistence`), PostgreSQL, S3 asset bytes.
- **Nuance**: the v1.0.0 agent workbench durable sessions are opt-in and **PostgreSQL-backed by design** (`OPENMAIC_AGENT_RUNTIME_ENABLED=true` + `DATABASE_URL`); browser-only mode does not provide durable workbench sessions.
- P2P does **not** introduce a database merely because OpenMAIC supports one.

## 9. Security / resource boundary (bounded static)

- Secrets: server-side provider config only; credentials never reach the browser; `server-providers.yml` / `.env*` gitignored (only `.env.example` tracked); no committed keys found; opt-in `ACCESS_CODE` HMAC-signed cookie auth.

- Generated/interactive HTML: runs in learner's browser; exported HTML self-contained with inlined assets — containment review deferred to the execution-registration gate.
- Local providers: operator-run services; OpenMAIC is a client, not a sandbox host.
- No broad penetration test — bounded static assessment only (as instructed).
